## 🛠️ Setup

To install dependencies:

```bash
npm install
```

To start the development server:

```bash
npm run dev
```

---

## 📄 Exam Submission

You can upload your exam file (e.g., PDF or DOCX) directly into this repository under a new folder called `exam/`.

```bash
mkdir exam
mv your-exam-file.pdf exam/
```

Alternatively, you can link to the document hosted on Google Docs:

👉 [Click here to view the exam in Google Docs](https://docs.google.com/document/d/YOUR_DOCUMENT_ID_HERE)

> Replace `YOUR_DOCUMENT_ID_HERE` with your actual Google Docs file ID or full URL.
